## 答辩口径

- **已实现**：架构、策略代码、ESPHome 配置、HA 报表配置、文档。
- **已验证**：11 组模拟器/协议测试、ESPHome 配置校验、`bench-csi` 与生产房间编译；真实 ESP32-S3 单板的启动、PSRAM、I2C 扫描、ADC 和 5 kHz PWM 配置；模拟传感器驱动真实控制器与 PWM；ESPectre Direct API 真实输出 64 子载波 CSI，NAS 预览已接入并保持约 100 pps。
- **未验证**：LD2410/INA226/照度/24 V 灯路/HA 整机联调；真实 CSI 的人员走动相关性、距离/穿墙/误报和长时间稳定性；照度与计量精度、PWM 波形、满载温升/EMI、HA 仪表板实机显示。
- **数据口径**：页面原始频谱来自 ESPectre CSI；`fluctuation_pct` 是相邻帧形状变化的派生指标，不是 RSSI 或绝对干扰功率。房间、功率和电量目前仍是 mock。
- **现场复核条件**：当前开发机不在原测试网段，NAS 与设备地址本轮不可达；答辩引用的是切换网络前的实测记录，下一轮需回到同一 2.4 GHz 网络重新核对帧计数与来源。
- 只有单板或模拟台架时，展示代码、测试记录、构建结果和台架日志；不播放伪造的实物运行画面，不把编译或模拟通过说成整机验收。
